Install vRAM

Download the Debian package and its checksum file into the same directory. Verify the package before installing.

Download vRAM 0.6.7 Download checksum

Install the package

sha256sum --ignore-missing -c SHA256SUMS
sudo apt install ./vram-host_0.6.7_amd64.deb qemu-system-x86 fuse3
Install low-latency host swap

The kernel driver stores uniform pages inline and releases literal frames when Linux frees their swap slots. Download the amd64 DKMS package.

sha256sum --ignore-missing -c SHA256SUMS
sudo apt install "linux-headers-$(uname -r)" ./vram-kernel-dkms_0.1.1_amd64.deb
sudo systemctl enable --now vram-kernel.service
swapon --show

Plan the workstation

Use your domain XML to read the configured guest limit. vRAM uses the lower of that limit and the platform maximum.

vram-machine capacity --domain-xml workstation.xml
Qualify the full target

With the backing space free, this command temporarily reserves the full target, verifies dense pages, and releases the files. The example floors are in MiB/s.

vram-machine qualify --domain-xml workstation.xml \
  --min-read-mib-s 100 --min-write-mib-s 50
Boot your workstation

Substitute your bootable disk and its usual QEMU options. Repeat --backing-dir before the double dash to pool filesystems.

vram-machine run --state "$XDG_RUNTIME_DIR/workstation" \
  --domain-xml workstation.xml -- \
  -accel kvm -drive file=workstation.qcow2,format=qcow2
